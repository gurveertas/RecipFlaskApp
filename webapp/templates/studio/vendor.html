How this step works — choosing a vendor

Every Studio article belongs to a vendor. Pick one to see and generate topics for it.

P1–P5 badge
Commercial priority, set in Manage vendors. P1 is highest. A vendor needs a priority before topics can be generated, and higher priority raises topic scores.
certifications / courses
What the Vendor Knowledge Base holds for this vendor — the writer uses these as real facts and CTA targets, so richer data means better articles.
live on site
Published pages on rededucation.com about this vendor, from the site scrape — the best read on where coverage already exists and where it doesn't. A comparison post covering two vendors counts for both.
in this tool
Work started here, split into mutually exclusive stages that add up to the total — each article appears once: in brief (never written), needs fixes (written but QA or REACS is holding it), ready (both gates passed, not sent yet), pushed (a draft now exists in WordPress).
