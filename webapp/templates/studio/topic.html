How this step works — generating & choosing topics

The AI proposes ideas; a fixed scoring formula decides (commercial 40% · SEO 25% · AI-visibility 20% · vendor fit 15%, minus ranking difficulty). Difficulty is measured from the live Google top-10 for each keyword, not guessed.

ideas count
How many to generate per batch (each costs ~1 Serper credit for the SERP measurement).
theme
Optional steer for the whole batch, e.g. “zero trust” or “career switchers”.
score
The formula's 0-100 opportunity score. ≥65 auto-approves as create; 45-64 is parked; below is rejected.
gap / overlap
Checked against real published rededucation.com posts. gap = uncovered ground. overlap = a similar post already exists (linked) — decide if a second is worth it.
Create brief
Runs live research for the topic and drafts a structured brief. Refuses if no verified sources are found — the writer never invents facts.
