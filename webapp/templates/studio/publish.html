How this step works — what publishing does and doesn't do

Only ever creates a draft. Nothing this tool sends can go live; publishing stays a human action inside WordPress.

Author
WordPress requires an author on every post — there is no “none” option — and the theme prints that user's public display name on the article. The named expert still appears in the body as “Technically reviewed by …”, which we render and which is independent of who owns the post.
Permissions
Publishing as another user needs the edit_others_posts capability (Editor or Administrator). An Author-role token doesn't error — it silently reassigns the post to itself.
By hand
The featured image is attached by an editor in WordPress. Tags aren't sent at all: the site's tag vocabulary is legacy news terms, none of which fit these articles.
Pushing twice
Blocked while the draft still exists — a second push would create a duplicate rather than update it. If the draft is deleted in WordPress, the article becomes pushable again.
